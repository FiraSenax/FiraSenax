### Building

**[KeyMelier](https://github.com/FiraSenax/KeyMelier)** – *the sommelier for your security keys.*
A free desktop app for macOS, Windows and Linux that checks FIDO2 security keys from any
vendor (authenticity, known vulnerabilities), shows which accounts depend on which key,
and helps with backups and lost keys. It is young – if you have a security key, I would be
glad about a test report or an issue.
